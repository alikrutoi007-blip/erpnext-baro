## Current Blocker

Frappe Cloud is currently returning `504 Gateway Timeout` even for lightweight authenticated API calls.

This is a site/runtime availability issue, not a schema validation issue.

Official Frappe Cloud reference:

`https://docs.frappe.io/cloud/site/common-issues/site-slow-504-gateway-timeout`

Relevant interpretation:

- 504 can happen when web workers are busy with previous requests.
- Slow API/list/report requests can block the site.
- Frappe recommends checking the site analytics and the `Slowest Requests` chart.
- If a pattern is visible, optimize that endpoint; if not, the site/server itself may be slow.
